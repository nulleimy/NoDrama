## Runtime Generate Smoke Matrix

`npm run verify` is deterministic and does not require a live app server. The `/api/generate` runtime smoke matrix is manual and should be run against a local dev or production server.

Terminal 1:

```bash
npm run dev
```

Terminal 2:

```bash
npm run smoke:generate
```

The smoke matrix uses `NODRAMA_SMOKE_BASE_URL` when set, otherwise it calls `http://localhost:3000/api/generate`.

Optional metadata-only report:

```bash
npm run smoke:generate -- --write-report
```

Reports are written to `data/runtime/smoke-results/latest.json`. They include scenario ids, input previews, input hashes, detected metadata, forbidden vocabulary hits, and pass/fail status. They do not store full generated outputs.
