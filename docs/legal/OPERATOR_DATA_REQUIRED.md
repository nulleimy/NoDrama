# NoDrama Operator Data Required Before Launch

The following factual data must be supplied before the public commercial Terms of Service and Privacy Policy can be finalized:

- legal operator/controller name
- registered/business address
- company/registration number where applicable
- VAT status/number where applicable
- support/legal contact
- privacy/data-subject-request contact
- target customer jurisdictions
- governing-law/consumer-rights review outcome

These values were intentionally not invented during the repository licensing baseline.
