# NoDrama — Phrase Quality Engine

## Purpose

Bundle 7 adds quality ranking and UX highlighting to the phrase engine.

## What it does

- scores candidate phrases
- ranks better phrases higher
- filters overly similar alternatives
- marks the first reply as recommended
- exposes lightweight phrase engine metadata to the UI

## Scoring signals

- length
- style match
- channel match
- humor quality
- naturalness markers
- anti-cringe result

## UX impact

The UI now shows:

- Recommended
- Alternative
- Firm option
- Follow-up
- subtle engine/category/style metadata

## Why

The product should not just generate more replies. It should choose better replies.
